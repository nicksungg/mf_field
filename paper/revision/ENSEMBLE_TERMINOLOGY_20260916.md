# Ensemble terminology revision

The latest review revision now uses **ensemble fitting** for selecting and combining the trained models from reserved fine examples. After its definition, these input and fine field pairs are called **fitting examples**. The manuscript uses **surrogate model** for an individual complete inference procedure, **surrogate library** for the nine available models, and **ensemble** for their weighted combination. Shortened references to a model retain the same meaning.

These terms are applied across the abstract, main text, appendices, captions, table labels, plot labels, algorithm, and README. Section headings now include “Surrogate model library” and “Ensemble fitting budgets and evaluation.” The distinction between surrogate training, ensemble fitting, and evaluation remains explicit.

The manuscript equations and the ERA5, mechanism, and individual model numerical summaries are unchanged from the backup made immediately before this revision. The manuscript still has nine main pages and 42 total pages. Structural, numerical, terminology, and layout checks pass.

Program interfaces, archived data keys, source filenames, internal cross reference labels, historical revision records, and bibliographic titles retain their original spelling for compatibility and accurate attribution. The original manuscript directory is untouched. The pre edit backup is stored in `../automf_revision_backups_20260916/before_ensemble_terminology.zip`.
