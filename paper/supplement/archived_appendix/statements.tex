\section{Reproducibility, AI use, and ethics statements}
\label{app:statements}

\subsection{Reproducibility statement}
We retain the datasets, surrogate implementations, training scripts, data
preparation routines, and experiment records used in this study. These artifacts
support reproduction of data preparation, surrogate training, ensemble fitting,
and evaluation across the 22 datasets. The manuscript package contains the manuscript,
bibliography, numerical snapshots, plotting and table scripts, and a workbook
of reported values. A portable ensemble fitting program accepts saved model
predictions and reserved targets, fits and saves weights, and combines new
predictions without their evaluation answers. Input identities, source hashes,
individual error matrices, fitting protocols, and replay checks connect those
outputs to the reported scores. Appendix~\ref{app:protocol} describes training
recipes and case assignments. The training code and datasets are retained in
the benchmark and experiment archives, alongside the manuscript package.
The verified clean package rebuild covers ensemble fitting, saved prediction
evaluation, tables, and figures. It does not retrain the surrogate library or
rerun the simulation solvers.

\subsection{AI use statement}
Generative AI assistance was used to develop and critique hypotheses, design experiments, implement and debug
code, inspect data provenance, interpret results, formulate and check mathematical arguments, search and summarize
literature, draft this manuscript, generate plotting code, and format references.
The reported values are extracted from experiment artifacts. Automated checks verify the
tables, citations, and document build. Scientific claims and source attributions
remain the authors' responsibility.

\subsection{Ethics statement}
Field surrogates can reduce the cost of repeated scientific calculations, but inaccurate
predictions can mislead engineering or climate decisions. Benchmark error alone does not
establish physical validity, reliable uncertainty, or suitability for operational use.
The paper identifies the available model comparisons, dataset limitations, and
the distinction between reanalysis and direct observations. Data provenance and redistribution
permissions require review before a public release.
