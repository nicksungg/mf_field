# Iteration 1 — `r2s2_stacked` / batch 1

## Search rationale

The stream's pre-directed B1 (program.md §12.2) is: condition → **pseudo-LF emulator** →
**frozen round-1 DC corrector**. Three things must be established before any proposal:
(a) does the "emulate the coarse field, then apply a learned corrector" pipeline already
exist in the PDE-surrogate literature; (b) does the parametric two-stage (parameters → LF →
HF) variant exist *with no LF solve at test*; (c) is the generated-input distribution-shift
problem for a frozen downstream module named and quantified anywhere. Terms 1–3 map to
(a)–(c).

## Search terms used

1. `neural emulator of coarse solver feeding learned correction network multi-fidelity surrogate stacked`
2. `generate low-fidelity field from parameters then correct to high-fidelity neural operator two-stage`
3. `distribution shift cascaded surrogate model downstream network trained on real inputs receives generated inputs exposure bias`

## Findings

### Term 1 — emulator + learned corrector

- **Learned Correction / solver-in-the-loop framing is standard.** Results surface
  "Learned Correction (LC): a neural network learns to predict the correction for a fast but
  inaccurate coarse numerical solver" — the corrector consumes a **real** coarse solve.
  Topic page: https://www.emergentmind.com/topics/neural-surrogate-modeling
- **Neural-network multigrid solver** (Margenberg et al.), https://arxiv.org/pdf/2008.11520 —
  an RNN predicts the correction of a *coarse mesh solution prolongated onto finer levels*.
  Again: the coarse solution comes from an actual coarse solve inside the multigrid cycle.
  (WebFetch on the PDF returned no readable text — binary parse failure; claim above rests on
  the search-result snippet only, flagged as such.)
- **Multi-fidelity Residual Neural Processes (MFRNP)**: models the residual between the
  aggregated lower-fidelity output and the HF ground truth — surfaced only as a snippet,
  not fetched.
- **Neural Emulator Superiority** https://arxiv.org/pdf/2510.23111 and
  **Coarse Graining with Neural Operators** https://arxiv.org/pdf/2408.05177 — adjacent
  (emulators that beat their coarse training data), not stacked-corrector work.

### Term 2 — parameters → LF → HF, two stage

- **Bifidelity data-assisted neural networks in nonintrusive ROM** (Lu & Zhu 2019),
  https://arxiv.org/abs/1902.00148 — **VERIFIED BY ABS FETCH**. POD basis for HF + shallow
  MLP for HF reduced coefficients, **with low-fidelity data as the network's input feature**.
  Decisive quote from the fetched abstract: "incorporate the features extracted from the
  low-fidelity data as the input feature … enables the decoupling **the high-fidelity
  simulation** from the online stage." So the *LF solve is still run online*; it is the HF
  solve that is eliminated. **This is round 1's regime, not round 2's.**
  *Correction recorded*: an earlier WebFetch of the same paper's PDF asserted "a neural
  network predicts the low-fidelity solution directly from input parameters" — that summary
  is **not supported** by the fetched abstract and is discarded. Do not cite it.
- **Pretrain-Finetune Neural Operator (PF-NO)** for structural dynamics,
  https://www.sciencedirect.com/science/article/abs/pii/S0141029625016098 — two-stage
  training (LF-pretrain → HF-finetune), LF data *generated by Newmark-β* for **training**.
  This is r2s3's mechanism (LF as training signal), not a test-time stack.
- **Two-stage physics-informed FNO** (super-resolution of flow fields),
  https://iopscience.iop.org/article/10.1088/1873-7005/ae79a2 — "Global Capture + Local
  Correction"; stage 1 consumes **low-resolution data** as input. Requires an LF field at
  test.
- **Neural operator-based super-fidelity / warm-start**, https://arxiv.org/pdf/2312.11842 —
  maps LF solutions to HF ones to warm-start an iterative HF solver; LF solve required online.

### Term 3 — generated-input distribution shift

- The vocabulary exists but is owned by **diffusion/sequence models**: exposure bias =
  "mismatch between the model's input during training (ground truth) and inference (previously
  generated samples)". e.g. https://arxiv.org/html/2305.15583v5 (shifted time steps),
  https://arxiv.org/pdf/2507.10072 (frequency regulation for exposure-bias mitigation).
- **Cascaded neural network surrogate modeling** for water-supply distribution,
  https://www.tandfonline.com/doi/full/10.1080/19942060.2025.2453080 — cascade is
  classifier→regressor, not emulator→field-corrector.
- No usable result yet for "frozen corrector fed a *generated* coarse field" specifically.

## Interpretation

Every stacked/corrector result found so far keeps a **real** LF solve in the online path —
the literature's "two-stage" almost always means (LF solve → correct) or (LF-pretrain →
HF-finetune), neither of which is round 2's regime. The genuinely open slot is therefore
*replacing the online LF solve with a learned emulator and measuring what the frozen
corrector loses*. Iteration 2 must attack that directly, plus the frozen/fine-tune/end-to-end
ablation question.
