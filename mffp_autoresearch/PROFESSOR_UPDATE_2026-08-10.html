Headline mechanism results (each from a causal probe):

  • The factorised head's discriminator is stage-1 residual saturation, not condition dimension. Controlled pair: allen_cahn and cahn_hilliard share cond_dim 19 yet differ 47× in stage-2 margin; fisher_kpp has the largest cond_dim (50) and the smallest margin. On fisher_kpp the loss to the affine floor is a hyperparameter clip (SELECT_MAX = 32 strands 0.0713 of condition-reachable energy; the head is better than affine inside its selected subspace, losing 17× more outside it). The cahn_hilliard win is broad-based (78–82 of 100 rows; survives an adversarial 10-row trim at 2.9–3.2× the certified floor).
  • The IC-reach effect is created at stage 1 and is approximability-limited, not information-limited. Fractional emulator-error removal 63.7% / 22.3% / 85.4% on ac/ch/fk; the zero-information IC null is worse than the no-IC control everywhere. The residual cahn_hilliard gap is approximability: its nearest-condition neighbour is 98% as different as a random sample.
  • The corrector stage is dead weight, decisively, for the second round running: the best stack arm beats its front-end-matched emulator-only control by 9–163× less than one minimum-detectable effect; round 2's 0.0061 null replicates at 0.0056. Its one dramatic failure (ifc_poisson seed-2 nRMSE 2.04 vs 0.15) was root-caused to a deterministic instrument defect: an unregularised spectral Wiener transfer fit from 3 samples amplifying 66× in a band where the LF carries no power — the identical mode as round 2's anchor instability; the promoted audit tool also flags the pfc anchor legs and the fluid guard cell.
  • LF-at-train's value is identifiability supply, quantified. The covered-input control arm (extra LF only at parameters HF already covers) learns the same function as the no-LF arm; supplying new distinct condition rows accounts for Ecov/Etotal ∈ [0.972, 1.024] on 30/30 cells. Recovery is a near-deterministic function of a measurable intermediate (condition-response alignment, r = 0.985) — batch 2 tests whether that mediator makes the LF-row ↔ HF-row exchange rate a law.
  • A seed-invariant hard subpopulation exists on cahn_hilliard: 27/100 test rows whose conditions are indistinguishable from training (max gap 0.45σ, NN ratio 1.02) but whose fields are 3.29× farther — and LF-at-train specifically repairs them (97% of that pair's gain).

3. Benchmark-integrity findings

  • The pfc scored cell was task-void (stop-the-line #1): the convention scores 64²→128², where the crystalline fields are band-limited below the coarse Nyquist — exact per-row copy gap ≤ 1.66e-6 on all 100 test rows; the certified reference 0.018257 was ~100% linear-interpolation error of the frozen lift. The real gap lives at 32²→128², which the convention never scores. Interim: report-only (ADR r3-0004); durable repair: ADR r3-0005, pending sign-off.
  • Checkpoint-resume can silently void a re-score campaign (stop-the-line #2): re-scoring on repaired data resumed completed checkpoints (resumed_from_step = 5000, train 1.3–2.9 s), so pre-repair weights were scored on post-repair arrays — and every existing hash/floor seam passed, because references recompute live while only the weights were stale. 32 legs quarantined + fresh-trained; anchor diff confined to the contaminated columns; a stale-checkpoint gate now runs inside the anchor builder. Fresh training improved every contaminated anchor — the contamination had been biasing comparisons in the flattering direction.
  • The audit instruments were themselves priced: the train_seconds staleness heuristic contributes 0 unique true positives and 62 false alarms over 859 legs and is being deleted; file mtimes are not a witness (the repair copy preserved them); only a content hash bound into the checkpoint separates a train-invalidating mutation from a benign test-split trim. Binding coverage today: 0/18 — building that instrument is r3s4's batch-2 card.
  • Tolerance-setting now has a measured metrology floor: an audit clause fired at 1.106e-9 against a 1e-9 tolerance — ~70× below the float64→float32 loader seam's own spread. Per-dataset ULP-band analysis puts correct tolerances between 2e-9 and 0.31 (sod_1d, where an exact-equality std == 0 guard amplifies one ULP 8.4e6×; guard-cell bounded, nothing shipped is wrong). Batch-2 contract change: floor tolerances at max(1e-9, measured band).
  • mdd_scored = 0 means unobservable, not zero: on both ifc cells the reference's own uncertainty cannot be observed from this round's data, understating absolute bars ~2.15×; no live claim flips.
