## 7. What is UNKNOWN

1. **Whether a role-resolved binding is achievable at all in this regime.** The routed fix says "train and test hashed separately". But in the round-3 regime LF is a *train-time-only* input and test LF exists only to build the copy-LF denominator. So the honest partition is not two roles but at least five (`train_cond`, `train_hf`, `train_lf`, `test_cond`/`test_hf`, `test_lf`), and the correct verdict for a given mutation **depends on which roles the family actually read**: a train-LF-only change invalidates an LF-consuming arm's weights and is a no-op for a condition-only arm on the identical dataset. Nobody has measured whether that distinction is decidable from a checkpoint. It is the one genuinely MF-specific increment over the published halves (Atlas attestation, Check-N-Run position state, TRAINCHECK invariants, dataflow staleness).
2. **The false-positive price of each increment.** We know the wall-clock rule's price (0 unique TPs, 62 FPs / 859 legs). We do not know the price of the *whole-dataset* hash (how many benign test-only changes it would force a retrain on) nor of a *train/test-split* hash that ignores roles. No labelled corpus exists in this project on which any of these can be scored — the 20 ground-truth stale legs are all train-invalidating, so they cannot measure a false positive at all.
3. **Whether the ULP-band table is reproducible.** Batch 1's E2 estimator is a max over 8 random dithers at seed 0 — a stochastic *lower* bound on the band. Nobody has re-measured it at a different seed or a larger B, so we do not know the estimator's own reproducibility, which is the thing an F1 tolerance is about to be pinned to.
4. **Whether the sod_1d remedy is a no-op elsewhere.** Dropping zero-variance condition dimensions is Titolo et al.'s remedy shape, but it has never been run: we do not know that it collapses sod_1d's band, and (more important) we do not know that it leaves the nine other datasets' floors bit-identical. A remedy that silently perturbs a scored floor would be worse than the defect.
5. **Whether the fit-set-size seam is verdict-changing on the scored panel.** r3s1 measured three cells; nobody has read the deltas against the *certified* `tau_rel` on all five scored cells, so "the seam is real but sub-verdict" is a plausible, untested statement.
6. **Whether any live reported number still reads a pre-box-swap pfc anchor column** (B1 part 7's explicit residual). The mechanism analyzer states plainly it did not check; it needs the anchor-consumer graph.
7. **What binding coverage is actually attainable.** Coverage is 0/18 on the flagged legs and 0 everywhere else, because no family in any round has ever written a data hash into `last.pt`. Whether writing one is compatible with the frozen contract CLI, with checkpoint-resume, and with both on-disk layouts is untested.
