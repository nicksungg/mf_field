Key finding: the canonical breakpoint work states its own limitation verbatim — "Ideally, one would like to be able to extrapolate the entire scaling behavior by fitting only points from before the break" and "there does not (currently) exist a way to extrapolate the scaling behavior after that additional break" [cite: https://arxiv.org/pdf/2210.14891]. Proxy-model genre is small/short *trained* networks for data selection (snippet-only). MF allocation is variance/MSE-minimising DoE, not breakpoint prediction. → `iteration_1.md`

### Turn 2 — `kernel ridge ... predicts neural network learning curve ... NTK` / `when does low-fidelity data stop helping correlation threshold` / `preregistration ... pre-specified quantitative prediction`
Key findings: a training-free theory *does* exist but predicts **KRR's own** curve on image data from "the empirical data covariance matrix and an empirical polynomial decomposition of the target function", with an **absolute-MSE-threshold** sample complexity [cite: https://arxiv.org/pdf/2510.14878]. The MF-emulator benchmark fetched is an architecture/encoding study with LF present at prediction time and zero "a priori" content [cite: https://arxiv.org/html/2512.02868]. Pre-registration for predictive modelling is an established, citable methodology [cite: https://arxiv.org/abs/2311.18807]. → `iteration_2.md`

### Turn 3 — `knee elbow detection Kneedle` / `neural operator ... predict how many training samples needed` / `scaling laws for transfer effective data transferred`
Key findings: knee detection is packaged software (Kneedle; Satopää et al. 2011) [cite: https://kneed.readthedocs.io/en/stable/]. PDE-surrogate sample counts are reported empirically, never forecast (snippet-only). The exchange-rate formalism is fully preempted — "D_T = effective data transferred = k(D_F)^α (N)^β" — while that paper's own future-work list contains "A method to **cheaply predict the ideal pre-training ratio** for a pair of datasets A and B ... for which we have limited data" [cite: https://arxiv.org/pdf/2102.01293]. → `iteration_3.md`

### Turn 4 (refutation 1) — `a priori prediction of saturation point multi-fidelity ...` / `subgroup learning curves heterogeneous saturation` / `training-free proxy predicts where adding more low-fidelity data stops improving`
Key findings: the closest MF work is **reactive**, not predictive — "If the improvement falls below a predefined local tolerance, the algorithm advances to the next fidelity", with saturation observed post hoc and attributed to "an intrinsic property of the underlying chemical space" [cite: https://arxiv.org/html/2606.02662]. The canonical survey names the problem — "**Projective early stopping means to predict the saturation point before it is reached**" — defines **b_sat**, the **plateau**, and the **pre-exponential point**, and states "the only line of research utilising meta-features for learning curve modelling is the work of Leite and Brazdil (2008, 2010); Ruhkopf et al (2023)", both of which still consume a **partial empirical curve on the target dataset** [cite: https://arxiv.org/pdf/2201.12150]. Term 3 returned **no usable results** ("knee" collides with biomechanics). → `iteration_4.md`

### Turn 5 (refutation 2, cap) — `cheap surrogate predicts another model's data scaling curve zero-shot` / `hard examples never learned more data does not help long tail`
Key findings: "zero-shot" LC prediction exists but means an unseen task inside a **corpus of ≤30 measured sibling LCs**, via latent-variable multi-output GPs, on NLP, with no breakpoint statistic [cite: https://arxiv.org/html/2510.16743]. The canonical "more data does not fix this subpopulation" account is **rarity + memorization** [cite: https://arxiv.org/pdf/1906.05271], which is not our mechanism (our mask is 27/100 rows, in-distribution, condition-close). → `iteration_5.md`
