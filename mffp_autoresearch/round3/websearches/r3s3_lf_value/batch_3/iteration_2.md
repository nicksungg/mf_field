# iteration_2 — r3s3_lf_value batch 3

## Search rationale

Turn 1 established that the canonical breakpoint literature (BNSL) is a *fitting* form needing points at/after the break. Two preemption routes remain open. (i) **Training-free theory that predicts a learning curve from data statistics alone** — if such a theory already predicts sample-efficiency thresholds from a covariance-style descriptor, our surrogate is an instance of it. (ii) **MF-specific a-priori criteria** for when LF stops paying — the "correlation threshold" genre. Third term probes the methodological frame the card is being asked to use: **pre-registration of a quantitative prediction in predictive modelling**, to check whether that is an established practice we should cite rather than invent.

## Findings

### Term 1 — training-free learning-curve theory (**body fetched**)
Search returned "Predicting kernel regression learning curves from only raw data statistics" (https://arxiv.org/pdf/2510.14878), "A Comprehensive Analysis on the Learning Curve in Kernel Ridge Regression" (NeurIPS 2024, https://proceedings.neurips.cc/paper_files/paper/2024/file/2bfb9435865f86ecaf7a43c49a00ba04-Paper-Conference.pdf), plus NTK-theory items (2412.18756, 2607.06382) and data-pruning work (2406.03057).
**Fetched** `https://arxiv.org/pdf/2510.14878` (Karkada, Turnbull, Liu, Simon — ICLR 2026; 71 pp, 187,865 chars). Verbatim: "We give a theoretical framework that predicts learning curves (test risk vs. sample size) from only two measurements: the empirical data covariance matrix and an empirical polynomial decomposition of the target function f*." And: "We are able to accurately predict the KRR sample complexity, including constant prefactors, for learning polynomials of the ImageNet dataset"; "we predict learning curves for KRR on image tasks without requiring omniscient knowledge of the feature statistics (i.e., without ever constructing or diagonalizing a kernel matrix)."
Scope, read off the fetched body: kernels are Gaussian / Laplace / ReLU-NNGP / ReLU-NTK; datasets CIFAR-5m, SVHN, ImageNet-32; the predicted object is **KRR's own curve** (self-prediction, not a deep-net curve), the reported threshold statistic is "the sample complexity required to achieve MSE ≤ 0.5" (an **absolute-threshold crossing**), and the paper has an explicit failure section ("E WHAT BREAKS THE HEA? CASE STUDIES OF THREE CAUSES OF FAILURE"). No PDE, no multi-fidelity, no breakpoint/knee statistic, no held-out-cell pre-registration.

### Term 2 — MF a-priori criteria for LF value (**body fetched**)
Search returned: "Assessing the performance of correlation-based multi-fidelity neural emulators" (https://arxiv.org/html/2512.02868); "Review of multi-fidelity models" (https://arxiv.org/html/1609.07196v5); "Finding efficient trade-offs in multi-fidelity response surface modelling" (tandfonline, paywalled); "Applying Multi-Fidelity Bayesian Optimization in Chemistry" (https://arxiv.org/pdf/2409.07190); the batch-2 survey again (2408.17075). Search-snippet claims (bodies NOT read, so cited as snippet-only): a sample correlation coefficient > 0.9 between fidelities is the rule-of-thumb threshold, "a high correlation by itself is no guarantee", and misleading LF can make MF *worse* than single-fidelity.
**Fetched** `https://arxiv.org/html/2512.02868` (Villatoro, Geraci, Schiavazzi, 2 Dec 2025, 120,527 chars). It is an **architecture/encoding benchmark** (MLP vs SIREN vs KAN, three complexity configurations, coordinate encodings) over analytical and PDE test cases with 1–20 input dims and scalar/low-dim outputs; LF is **available at prediction time** (the emulator maps LF→HF). It reports MSE and CoV over 4 repetitions; it contains **no a-priori prediction of a data-count threshold** ("a priori" returns zero matches in the fetched body).

### Term 3 — pre-registration as method (**body fetched: abstract page**)
Search returned: "Pre-registration for Predictive Modeling" (https://arxiv.org/abs/2311.18807, Hofman, Chatzimparmpas, Sharma, Watts, Hullman); "Perspectives on Machine Learning from Psychology's Reproducibility Crisis" (https://arxiv.org/pdf/2104.08878); "Preregistration for Experiments with AI Agents" (https://arxiv.org/pdf/2606.11217); "Prediction scoring of data-driven discoveries for reproducible research" (https://arxiv.org/pdf/2211.10314); COS prereg (https://www.cos.io/initiatives/prereg).
**Fetched** the arXiv abstract page for 2311.18807, verbatim: "Amid rising concerns of reproducibility and generalizability in predictive modeling, we explore the possibility and potential benefits of introducing pre-registration to the field ... challenges such as overlooked contextual factors, data-dependent decision-making, and unintentional re-use of test data have raised questions". Snippet-level (COS): "At least one confirmatory test must be specified in each preregistration."

## Interpretation

The nearest neighbour to the card's *instrument* is now identified and fetched: 2510.14878 predicts learning curves and sample complexity from raw data statistics with no training — but it predicts **its own model class's** curve on image classification against an **absolute-MSE threshold**, which is exactly the statistic our slot is forbidden to use. Nothing in the MF literature retrieved so far supplies an a-priori, computable prediction of *where* the LF-supply curve stops paying; the MF genre's a-priori device is a correlation rule-of-thumb (> 0.9), not a location. Pre-registration is an established methodology with a citable ML-specific paper, so the card should cite it rather than present pre-declaration as an innovation. Turn 3 must close the remaining hole: knee/elbow **detection** methodology (is "step-max knee cap" a named statistic?) and any operator-learning / PDE-surrogate work that forecasts data requirements before training.
