Verbatim: "we formulate the prediction task as a **multitask learning problem**, where each task's data is modelled as being organized within a two-layer hierarchy ... we employ **latent variable multi-output Gaussian Processes**, enabling to account for task correlations and supporting **zero-shot prediction of learning curves (LCs)** ... We validate our framework on three small-scale NLP datasets with up to **30 LCs**." ⇒ "Zero-shot" here means **unseen task within a corpus of already-measured learning curves from sibling tasks**; the method's input is other LCs plus hierarchy structure. It predicts a smooth LC / probabilistic scaling law, on NLP, with **no breakpoint statistic** and **no multi-fidelity axis**. It does not predict from a training-free structural descriptor of the target problem's own data.

**Fetched** https://arxiv.org/pdf/1906.05271 (38 pp, 111,023 chars). Verbatim: "a dataset of n samples ... will have some subpopulations from which just a single example was observed ... To predict more accurately on a subpopulation from which only a single example was observed ... the learning algorithm needs to **memorize** the label of the example ... **based on observing a single sample from a subpopulation, it is impossible to distinguish samples from 'atypical' subpopulations from those in the 'outlier' ones**."
⇒ The canonical account of "a subpopulation more data does not fix" is **rarity/long-tail + memorization**. Our K3 mask is **not rare** (27 of 100 test rows, in-distribution, condition vectors *closer* than bulk at 1.015–1.016×) — the mechanism is different, so Feldman is a nearest neighbour, not a preemption.
