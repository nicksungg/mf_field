Terms: (1) POD truncation criterion vs energy; (2) adaptive rank selection under few samples; (3) POD-NN mode retention / mode-wise error.
Key findings: energy-based truncation "can discard low-energy modes needed to capture small-scale features" and NN-manifold methods "employ energy-based selection" — SparseModesNet selects modes by *reconstruction* error [cite: https://arxiv.org/abs/2605.27756]; a POD-NN surrogate publishes exactly the truncation-vs-regression error decomposition, "identifying a POD-truncation error floor that defines the surrogate's accuracy ceiling" [cite: https://par.nsf.gov/biblio/10684905]; rank chosen jointly with the regressor by LOO-CV [cite: https://doi.org/10.3390/en19102387, snippet only]. Key findings: omitted-variable subpopulation failure is classical statistics (snippet-level, missing-data literature); PDE-surrogate UQ returned here is **epistemic** and band-shaped, not subpopulation-identifying [cite: https://arxiv.org/abs/2603.11052].

### Turn 3 — slice discovery, gated residual boosting, ROM closure → `iteration_3.md`
Terms: (1) automatic slice discovery; (2) gated residual correction on reduced-basis coefficients; (3) two-level POD coefficient regression / closure.
Key findings: slice detection models "automatically identify underperforming groups of datapoints", with a benchmark and metrics [cite: https://arxiv.org/abs/2211.04476]; **Operator Boosting** trains stagewise residual corrections "starting from the empirical mean predictor" and incorporates each "through validation-selected shrinkage" on PDEBench/APEBench/The Well [cite: https://arxiv.org/abs/2606.17460]; discarded-mode influence is the classical ROM **closure** problem (snippet, [https://arxiv.org/pdf/2106.14954]) — adjacent vocabulary, dynamical not parametric.
