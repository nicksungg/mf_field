# Sharp-field PDE generator source

The solver package is in `mffp_sharp/`. Its PDE modules, sampling configurations, initial-condition encodings and verification code accompany the benchmark. See [solver sources and checks](PDE_SOLVERS.md), the [package guide](mffp_sharp/README.md) and the [benchmark dataset guide](../../../docs/DATASETS.md).

For the paper data, use the benchmark's standardized generation drivers and per-variant configuration records in the parent directory. `mffp_sharp/configs/sample.yaml` is an exploratory sampling recipe and does not by itself reproduce every finalized benchmark dataset. Private development notes and machine-specific instructions are omitted from this review copy.
